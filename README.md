# 🐻📞 BearPhone

Лёгкая, быстрая и конфиденциальная звонилка для Android — замена Truecaller без облака, рекламы и сбора данных.

- Без интернета: в манифесте нет разрешения `INTERNET`
- Без своей базы: журнал и контакты читаются из системы
- Без аудиофайлов: рингтоны и звуки уведомлений системные

## Что уже есть

| Экран | Возможности |
|---|---|
| **Набор** | T9-клавиатура (кириллица + латиница), подсказки из контактов, долгий тап на `0` — `+`, долгий тап на ⌫ — очистить |
| **Вызовы** | Системный журнал, группировка подряд идущих звонков, удаление, «изменить номер перед вызовом» |
| **SMS** | Диалоги, чтение, ответ, новое сообщение, «Копировать код» для SMS-кодов, счётчик непрочитанных. Системное SMS-приложение остаётся главным |
| **Контакты** | Поиск, избранные сверху, выбор номера, если их несколько |
| **Звонок** | Ответ/сброс, таймер, микрофон, динамик, удержание, тональный набор; работает поверх экрана блокировки |
| **Настройки** | Статус «звонилка по умолчанию», разрешения, звуки, 4 темы + своя, рамка/тень кнопок |
| **Блокировка** | Чёрный список, маски (`+7495*`, `8800*`), скрытые номера, «только контакты», журнал заблокированных |
| **Уведомления** | Входящий (full-screen), текущий разговор с таймером, пропущенный |

## Сборка

**Автоматически:** каждый пуш в `main` собирает APK в GitHub Actions.
Вкладка **Actions** → последний запуск → **Artifacts** → `BearPhone-N` (zip с APK).

**Локально:** открыть папку в Android Studio → Run.

Все сборки подписаны одним ключом (`keystore/debug.keystore`), поэтому новый APK ставится поверх старого без удаления.

## Структура

```
app/src/main/java/com/bearphone/app/
├── MainActivity.kt          единственная обычная Activity, вкладки — composable
├── InCallActivity.kt        экран звонка (поверх блокировки)
├── BearPhoneApp.kt          создание каналов уведомлений
├── call/
│   ├── BearInCallService.kt Telecom → CallManager, рингтон, уведомления
│   ├── CallManager.kt       состояние звонков (StateFlow) + действия
│   ├── CallNotification.kt  уведомления входящего/разговора/пропущенного
│   ├── CallActionReceiver.kt кнопка «Сбросить» в уведомлении
│   └── Dialer.kt            исходящий звонок, роль по умолчанию
├── data/                    чтение журнала и контактов
├── sound/                   системные звуки и вибрация
└── ui/                      экраны Compose и тема
```

## Требования

Android 8.0+ (`minSdk 26`), `targetSdk 35`.
